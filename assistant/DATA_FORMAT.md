# صيغة بيانات مكتبة مساعد الالتزام

هذا الملف مرجع لبوت الرصد اليومي (وأي محرر) عند تحديث المكتبة. عدّل فقط الملفات الثلاثة في هذا المجلد: `kb.json` و`arts.json` و`updates.json`. لا تعدّل `index.html`.

## kb.json — الوثائق (مصفوفة)
| الحقل | المعنى |
|---|---|
| `id` | معرّف إنجليزي قصير فريد (مثل `localre`) |
| `t` | عنوان الوثيقة بالعربية، ويتضمن رقم التعميم إن وُجد |
| `cat` | التصنيف: أنظمة / لوائح / قواعد / تعليمات / تعاميم / وثائق موحدة / مشاريع / إنفاذ / تقارير / تراخيص / عام |
| `d` | تاريخ الإصدار (YYYY-MM-DD) |
| `upd` | تاريخ آخر تحديث |
| `st` | الحالة: "سارٍ – أحدث تعميم" أو "سارٍ" أو "مشروع – غير نافذ" أو "ملغى – حل محله ..." |
| `iss` | الجهة المصدرة |
| `u` | رابط المصدر الرسمي |
| `v` | 1 إذا تم التحقق من مصدر رسمي، وإلا 0 |
| `kw` | كلمات بحث عربية مفصولة بمسافات |
| `p` | مصفوفة نقاط: أهم الأحكام بصياغة دقيقة مختصرة |

## arts.json — المواد والفقرات (مصفوفة)
| الحقل | المعنى |
|---|---|
| `d` | `id` الوثيقة في kb.json |
| `r` | المرجع، مثل `م44` أو `ف25-29` |
| `h` | عنوان المادة |
| `x` | مضمون النص الأصلي أو السابق، ولا يُحذف أبداً |
| `u` | اختياري: كائن التعديل `{by, date, kind, new}` |

قيم `u.kind`:
- `معدِّل`: النص الجديد حل محل السابق.
- `مكمّل`: أُضيف إليه، والسابق باقٍ.
- `مشروع`: مقترح غير نافذ.
- `بديل لاحق`: يسري من تاريخ مستقبلي.
- `تحقق`: قد يكون معدلاً.

و`u.by` تُكتب هكذا: "تعميم هيئة التأمين رقم ... بتاريخ ..."، ولا يُخترع رقم تعميم.

إذا عُدّلت مادة لها `u` من قبل، فانقل `u.new` القديم إلى `x` واكتب `u` الجديد، حتى يبقى السابق ثم الحالي.

## updates.json — سجل التحديثات (مصفوفة، الأحدث أولاً)
`{"date":"YYYY-MM-DD","source":"بوت الرصد اليومي","items":["وصف كل تغيير في سطر"]}`

## قواعد
- لا تحذف أي مدخل. الملغى يبقى، وتتغير حالته `st`.
- أضف فقط ما تم التحقق منه من مصدر رسمي أو خبر موثوق، مع الرابط.
- تحقق أن كل ملف JSON صالح قبل الحفظ.
